# ⚙️ Sistemas Automatizados - USJT

Repositório dedicado a disciplina de **Sistemas Automatizados** da Universidade São Judas Tadeu. 

Este espaço armazena todos os resumos das aulas, além da documentação do projeto final (A3) desenvolvidos ao longo do semestre.

## 📂 Conteúdo do Repositório

### 🚗 Projeto Final (A3) - Estacionamento Inteligente
O projeto principal da disciplina consiste na automação de um estacionamento utilizando Controladores Lógicos Programáveis (CLP).
* **`CLP - ESTACIONAMENTO INTELIGENTE`**: Lógica de controle e automação do projeto.
* **`Apresentação A3.pptx`**: Slides utilizados para a defesa do projeto.
* **`Relatório Final - A3 Sistemas Automatizados.pdf`**: Documentação técnica detalhada e formatada em ABNT sobre o desenvolvimento do estacionamento inteligente.

## 🛠️ Tecnologias e Conceitos Abordados

Ao longo destas aulas e do projeto, exploramos as seguintes tecnologias e conceitos do ambiente industrial:
* **CLPs e Lógica Ladder:** Estruturação de lógicas de automação e blocos de controle.
* **Instrumentação:** Funcionamento e aplicação de sensores (indutivos, capacitivos, ultrassônicos e de nível).
* **Redes Industriais:** Princípios de comunicação para sistemas automatizados.
